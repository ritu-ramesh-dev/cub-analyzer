Machine-learning analysis of codon usage bias to distinguish highly and lowly expressed genes in prokaryotes

How it works

Most amino acids can be written by several codons. Genes that a cell makes in large amounts (HEG) lean heavily on the "fast" codons that match its most plentiful tRNAs, while rarely made genes (LEG) use codons more randomly. The model learns these habits and reads them back from any gene.

  1. 1
    Read the gene

    The DNA sequence is cut into triplets (codons), in frame from the first base.

  2. 2
    Count codons

    How often each of the 64 codons appears gives 64 codon frequencies.

  3. 3
    Compare synonyms

    RSCU scores each codon against its synonymous codons (above 1 = preferred): 59 more values, 123 features in total.

  4. 4
    Random Forest

    200 decision trees, trained in Python with scikit-learn, look at the 123 features and vote HEG or LEG.

  5. 5
    Answer

    The share of trees voting HEG is P(HEG). 0.5 or more → highly expressed, otherwise lowly expressed.

Training data

208 real E. coli K-12 genes from NCBI: 104 known highly expressed (ribosomal proteins, translation factors, chaperones, energy metabolism) and 104 lowly expressed transcriptional regulators.

Train / test split

The model learns from 156 genes and is tested on the other 52, which it never sees. Duplicate NCBI records are removed and near-identical gene copies (like tufA / tufB) are kept on the same side.

Built in Python

The pipeline is the Jupyter notebook notebook/cub_model.ipynb: Biopython fetches the genes, pandas builds the features, scikit-learn trains and tests the forest, matplotlib / seaborn plot the results. The trained trees are exported to model/model-data.js, which this page runs.
